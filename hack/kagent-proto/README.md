# kagent.api.v1alpha1 client stubs

`internal/kagent/gen` holds the Go stubs of the kagent `SessionService` (plus the `common` and
`runtime` messages it uses), which the controller reads every Session's last turn from to clean up
the session directories. They are generated by `buf` (protoc-gen-go, protoc-gen-go-grpc) from the
protos under `kagent/` here, verbatim copies of `proto/kagent/api/v1alpha1/` in
`giantswarm/kagent-upstream` at the commit below (tag `v1.9.0`); `buf.lock` pins the `buf/validate`
dependency to the same commit's lock.

Do not edit the generated files. To move the pin, set `KAGENT_PROTO_COMMIT` in
`Makefile.custom.mk` and run `make generate-kagent` (needs `buf`, `protoc-gen-go` and
`protoc-gen-go-grpc` on the PATH); the target runs `goimports` over the output because the
repository formats every Go file with it.
